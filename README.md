# ShraddhaSetu

श्रद्धा का पावन सेतु

ShraddhaSetu is a devotional platform dedicated to providing authentic Hindu spiritual content in a clean and peaceful digital space.

The platform offers access to sacred texts such as:

- Hanuman Chalisa  
- Aarti  
- Mantras  
- Stotra  

Our vision is to make devotional reading simple, accessible, and distraction-free for everyone.
